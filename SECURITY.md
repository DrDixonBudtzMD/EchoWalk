# Security and Safety

EchoWalk is an experimental accessibility research prototype.

Please report security vulnerabilities privately through GitHub's security reporting features when available rather than opening a public issue with exploit details.

For safety-related problems—false proximity warnings, repeated missed obstacles, crashes while sonar is active, excessive audio output, or device-specific microphone/speaker failures—open an issue with the phone model, Android version, test environment, approximate obstacle distance, and reproducibility details.

EchoWalk is not a certified mobility or medical device and must not be represented as a replacement for a cane, guide dog, trained human assistance, or established orientation-and-mobility techniques.
